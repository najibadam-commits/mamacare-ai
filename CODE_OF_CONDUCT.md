# Code of Conduct

We follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): be respectful, welcoming and harassment-free; assume good faith; accept constructive criticism; focus on what is best for the mothers and health workers the project serves.

Unacceptable behaviour includes harassment, discrimination, personal attacks, and publishing others' private information (including any patient or user data - never post real health data in issues).

Report concerns to **conduct@REPLACE-ME.example** (the project owner must set this before publishing). Maintainers may remove contributions and ban participants who violate these rules.
